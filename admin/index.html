Connect your editor once.

The writing editor runs in Pages CMS and uses your GitHub sign-in. This page is the entrance; editing is protected by GitHub.

  1. Open Pages CMS and sign in with GitHub.
  2. Connect erxn-mcg/portfoliositee, then choose the branch containing this setup.
  3. Open Writing, add a note, and save when it’s ready for the blog.

First-time setup requires the site files and editor configuration to be added to your repository.
